# mojo-imkit v0.9.0

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

- Pure-Mojo image decoders: JPEG (baseline and progressive) and WebP (lossless, lossy, alpha), bit-exact against libjpeg-turbo and libwebp where the format is exact; `image_decode` picks PNG, JPEG or WebP.
- 29 generated themes plus amarbaro and amarbaro-light, all passing a WCAG contrast gate that covers text, labels, controls and status colours.
- A background and 8 icons per style in `assets/styles/` (30 styles, 6 MB).
- Text: six font sizes in the gallery, and `heading`, `caption`, `separator`, `badge`, `kv` widgets.

## Changes

### Added
- `imkit.jpeg` (`jpeg_decode`), `imkit.webp` (`webp_decode`), `image_decode` routing in `imkit.assets`.
- `imkit.styles` (`style(name)`, `STYLE_NAMES`), generated by `tools/gen_styles.mojo` from ComfyUI swatches; `imkit.contrast` (`contrast`, `theme_faults`).
- Themes `amarbaro()` and `amarbaro_light()` from the amarbaro.com brand tokens.
- Widgets `heading`, `caption`, `separator`, `badge`, `kv`.
- `assets/styles/<name>/bg.jpg` and `icons/*.png`; `scripts/style-assets.sh` builds the raw atlases into `.work`.
### Changed
- `flat` and `neon` controls are more visible (button fill vs panel); the gallery's preset buttons share their row and the style button sits on its own row.
- CI runs on Ubuntu 26.04; the CJK fallback font is resolved per distro.
### Fixed
- Selected-button and badge labels are black or white for their fill (grey labels on dark accents).

## Known limits

- AVIF is not decoded yet (in progress).
- The generated themes come from one swatch each; taste is not gated, only contrast.
- Animated WebP raises.

## Upgrade / run

```
pixi add mojo-imkit   # or uv: mojo-imkit 0.9.0
scripts/gallery.sh .work/shots   # renders every preset
```
