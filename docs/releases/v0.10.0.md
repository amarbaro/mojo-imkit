# mojo-imkit v0.10.0

**Released:** 2026-11-10 · **Commit:** `a7b256f` · **Previous:** [v0.9.0](v0.9.0.md)

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

- AVIF stills decode in pure Mojo: `image_decode` and `pack` now take PNG, JPEG, WebP and AVIF.
- The decoded YUV planes equal dav1d / avifdec sample for sample on 32 fixtures: 8, 10 and 12 bit, 4:2:0, 4:2:2, 4:4:4 and
  monochrome, alpha, superres, film grain, intra block copy, palette, all intra tools and all three loop filters.
- `avif_decode(bytes)` returns RGBA in the same layout as the other decoders.

## Changes

### Added
- `imkit.avifrgb.avif_decode`: AVIF to 8-bit RGBA (matrix and range from the file, bilinear chroma, alpha item).
- AV1 intra decoder modules: `av1obu` (OBU headers), `av1sym` (symbol decoder), `av1tab` (every spec table, generated from the
  spec text by `tools/av1_tables.mojo`), `av1tile` / `av1coef` (tile syntax), `av1recon`, `av1ipred`, `av1intrabc`, `av1lf`,
  `av1cdef`, `av1lr`, `av1grain`, `av1dec.decode_frame` (YUV planes); `avifseq.avis_info` (image sequence timing).
- CI runs the AVIF gates on the runner; 32 AVIF / OBU fixtures committed (232 KB, our own encodes).
### Changed
- `image_decode` picks AVIF by its ISO BMFF `ftyp` box.

## Known limits

- Inter frames are not decoded: an animated AVIF's first frame decodes, later frames raise; `avis_info` reads its timing.
- RGBA is not bit-exact with avifdec for subsampled or high bit depth files (float conversion vs libyuv fixed point).
- Speed is untuned: 1280x720 4:4:4 in 0.12 s, 56 MB peak RSS (one run).
