## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

- A text field no longer aborts the app after about 54 typed bytes when its buffer is copied from app state each frame.
- Typed text is read with a bound: at most 256 bytes per SDL text event and 1024 per frame.

## Changes

### Fixed
- `Ui.field` appends the frame's typed bytes in one step. Mojo 1.2.0 and the 1.3 nightly double a copied String field's capacity on each in-place append; per-byte appends reached a 96 GiB request (stock-review crash, 2026-11-09).
- `Window.poll` reads SDL text with `strnlen` (256) and caps one frame at 1024 bytes.
