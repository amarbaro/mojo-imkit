# mojo-imkit v0.6.0

**Released:** 2026-10-26 · **Commit:** the one tagged `v0.6.0` · **Previous:** [v0.5.0](v0.5.0.md)

## What it does

An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

- `Audio(rate)`: SDL3 mono float playback stream the app keeps fed.
- Public packaging: Apache-2.0, `scripts/ci.sh` for the CPU gates, a CPU `Ui` test, API page and quickstart.

## Changes

### Added
- `imkit.audio.Audio`; `tests/ui_cpu_test.mojo`; `examples/quickstart.mojo`; `scripts/ci.sh`.

### Changed
- `tools/gate.sh` is `scripts/local_gate.sh` (GPU and window gates); tests take the font from `IMKIT_FONT`.
