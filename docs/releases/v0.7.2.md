## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

<!-- 1 to 5 bullets a user would notice. Lead with the benefit, not the implementation. -->
- `Layer.set_image(px, w, h)`: one call puts a large picture (up to `UI_IMG` pixels) in the image pool.
- `Ui.field` and `Input.text`: a single-line ASCII text box fed by SDL text events; `Window.text_input(on)`.
- `Window.push(EV_TEXT, text=...)` delivers the text it was given, also when the string is built at run time.
- `Ui.button` takes a `color`.

## Changes

### Added
- `Layer.set_image`, `layer.image_fits`; `Input.text` (default empty), `Window.text_input(on)`, `EV_TEXT`, `Window.push(EV_TEXT, text=...)`; `Ui.field`, `Ui.field_focused`; `scripts/mutants.sh`.
### Changed
- `Ui.button` takes a `color` (default: the accent). `Input` has an explicit constructor so `text` can default; every existing `Input(...)` call builds unchanged.
### Fixed
- `Window.push(EV_TEXT)` handed SDL a pointer into a string freed when `push` returned; SDL reads it at `poll()`. A literal hid the bug; a run-time string polled back garbage. `Window` now keeps the bytes alive until `poll()` has read them.

## Known limits

<!-- Honest list: slow paths, unsupported cases, flaky upstreams, anything UNVERIFIED. -->
- `Ui.field`: append and Backspace at the end only; no cursor movement, selection, paste, key repeat or non-ASCII. Fixed width 360.
- `Input.text` carries UTF-8 as SDL sends it; `field` drops every byte outside 32-126.
- This release carries the work developed as v0.7.0 and v0.7.1 in the dev repo (never published; renamed dev-v0.7.0, dev-v0.7.1 there).
