## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

- Three themes, glass, neon and flat, switchable at run time; every widget reads theme roles.
- Unicode text (UTF-8, CJK through a fallback font) with glyphs rasterized on demand.
- New widgets: slider, menu, scroll list, table, plot; animation springs and DPI scaling.
- Frame cost down 70% (204 to 62 us for 150 commands) with `render_into`, no per-frame 3.7 MB readback.
- Rounded rects with border, glow and gradient, offset shadows, clip rects, backdrop blur for glass panels, PNG asset atlas.

## Changes

### Added
- `Ui.rrect`, `style`/`srect`, `glass`, `clip`/`unclip`, `icon_img`; `Assets` and `tools/pack_atlas` for offline Blender/ComfyUI PNGs.
- `Ui.slider`, `menu_begin`/`menu_item`/`menu_end`, `scroll_begin`/`scroll_row`/`scroll_end`, table and plot calls.
- `Ui.begin(input, dt)`, `animate(id, target)`; `Ui.set_scale`, `Window.scale`, `Input.logical`.
- `Theme` with `glass()`, `neon()`, `flat()`, `Ui.set_theme`; `examples/gallery.mojo`.
- `Layer.render_into(device buffer)`, `readback()`, `blur_from`, `set_scene`.
### Changed
- `Ui` holds the draw list as `ui.d`; counters are `ui.d.n`, `.dropped`, `.off`, `.bins`. Constants import from `imkit.draw` and `imkit.theme`.
- `button(color=0)` means the theme accent (was the fixed glass accent).
- `Font(path, sizes, fallback="")`; `Font.glyph` and `Font.width` are `mut` (they rasterize).
### Fixed
- Presets meet WCAG contrast 4.5 for text and 3 for graphics.

## Known limits

- No glyph eviction: a full atlas draws `?` (`font.full` counts them). No shaping (Arabic, Indic).
- `Ui.field` is still ASCII append + Backspace.
- PNG loader: 8-bit RGB/RGBA, not interlaced, CRC not checked. `set_assets` and `set_image` share pool offset 0.
- Glass blur needs the app to pass its scene (`set_scene` or `blur_from`).
- Merged gallery frames with UTF-8 and blur are not yet looked at by Mario (OCR only).
