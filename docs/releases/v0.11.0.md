## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

<!-- 1 to 5 bullets a user would notice. Lead with the benefit, not the implementation. -->
- Every imkit window now carries a Wayland app id, so KDE and GNOME show the app's own icon instead of a generic one.
- `IMKIT_SHOT=file.bmp` saves one rendered frame and exits: screenshots for docs and sites without a desktop capture.

## Changes

### Added
- `Window(..., app_id=)`: sets `SDL_APP_ID`; default `IMKIT_APP_ID`, else the title's first word lowercased.
- `IMKIT_SHOT=FILE` (+ `IMKIT_SHOT_FRAME`, default 30): reads the frame back from the renderer, saves BMP, exits 0.

## Known limits

<!-- Honest list: slow paths, unsupported cases, flaky upstreams, anything UNVERIFIED. -->
- The app id only helps when a matching `<id>.desktop` file is installed.
- `IMKIT_SHOT` captures the renderer output at the window's logical size, not the desktop.
