# mojo-imkit v0.8.1

**Released:** 2026-11-09 · **Commit:** `bf8770c` · **Previous:** [v0.8.0](v0.8.0.md)

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
An immediate-mode GUI for Mojo apps, drawn by one GPU compose kernel over the app frame. System SDL3 presents the window and FreeType builds the glyph atlas.

## Highlights

<!-- 1 to 5 bullets a user would notice. Lead with the benefit, not the implementation. -->
- An app that composes into its own buffer holds 5.6 MB instead of 13.5 MB (9.3 MB through SDL `render()`).
- Nine bugs fixed: clip nesting, NaN and infinite commands, UTF-8 Backspace, glyph-cache key collision, PNG header checks, `set_image`/`set_assets` overwrite, DPI scale for glass and icons, missing font sizes, scroll/axis with zero or NaN.

## Changes

### Added
- `tools/membench` (bytes, mallocs, compose time) and `tools/uibench` (CPU frame time).
- `scripts/ci.sh` dry-runs the mutants.
### Changed
- `Layer.scene`, `Layer.pixels` and the host font atlas are allocated when first used.
- `push` drops NaN commands and clamps coordinates: UI frame about 0.9 us slower (+4 %).
### Fixed
- The nine bugs above, each with a test that failed before its fix.
